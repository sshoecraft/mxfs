## Current test status — use showstat.sh

To see the live status of the conditions matrix (which tests PASS/FAIL/PENDING/SKIPPED
for a given node count + transport), run from `/src/mxfs`:

```
./showstat.sh <N> <dlm>      # e.g. ./showstat.sh 2 tcp
```

It reads `/src/mxfs/criteria.json` (single source of truth, regenerated by
`scripts/gen_criteria.py`) and prints a table keyed by `<nodes>/<dlm>` condition.

- Per-test results are recorded into `criteria.json` under
  `categories[].tests[].runs["<nodes>/<dlm>"]` by `tests/suite/run_one.sh`.
- The run-time gating (MINNODES) is applied at DISPLAY time, not stored.
- `tests/suite/run_suite.sh <N> [nodes...]` runs the manifest; but as of
  2026-06-14 the COORDINATED multi-node tests (coord != none) are SKIPPED by
  run_suite.sh ("coordinated runner TBD") — only coord=none tests auto-run.
  The older `run.sh <N> <dlm>` coordinated runner described in
  [[sess-testinfra-2node-harness-validated-and-crash]] was the predecessor.

**Ship target for the current run: every test in `./showstat.sh 2 tcp` must PASS.**

When you agree that a task is a good fit for an agent team, ACTUALLY USE THE TEAM. Do not then proceed to do the work yourself in a sequential bash loop.

**Why:** The user explicitly asked for a team, I agreed it was perfect for a team, and then immediately did a sequential loop instead. This wastes the user's time and breaks trust. The Director skill explicitly says "same task x N targets = team, not a loop."

**How to apply:** The moment you identify N-target parallel work AND agree to use a team: create the team, create the tasks, spawn N workers in ONE message. Do not touch the work yourself. Do not "just do it quickly in a loop." The whole point of teams is parallel execution.

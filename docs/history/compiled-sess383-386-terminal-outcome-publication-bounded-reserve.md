## 4. #361 root: AGI unlinked head published in halves (sess384–385)
`docs/rulings/agi-unlinked-reload-stale-live.md` `docs/rulings/inode-publication-hole.md` `docs/history/docs/history/compiled-sess383-386-terminal-outcome-publication-bounded-reserve.md` `docs/history/docs/history/compiled-sess383-386-terminal-outcome-publication-bounded-reserve.md`
- Failure line: rename-over-existing → `xfs_droplink` → `xfs_iunlink_insert_inode` backref -ENOLINK → `xfs_iunlink_reload_next` → `xfs_iget(UNTRUSTED)` → `i_nlink!=0` → -EFSCORRUPTED inside a DIRTY txn → shutdown → #474A cascade. sess384 ruling: never reuse the -ENOENT destructive heal for an allocated nlink!=0 member; FUA home reads are not authoritative in a journaling FS; `XFS_IGET_UNTRUSTED` changes validation not freshness (upstream's cache ASSERT is DEBUG-only — log hit/miss first: P84-UNL-RELOAD-LIVE/-OK landed); the strong fix lives at the DLM release boundary (AGI and dinode must describe the SAME transition at handoff); containment principle: another node's local shutdown is not evidence every peer is corrupt — noino callbacks must be idempotent and never recursively force unrelated shutdowns.
- HOLE 1 measured (P85, `mxfs.inode_drain_probe`): `drain_inode_buffers` lacked the meta drain's three hardenings (no `_XBF_DELWRI_Q` skip, blocking lock, pinned/BLI fallthrough); on a green lap 34 dirty inode-cluster bufs skipped at release, 10/23 differed from in-core (Invariant 1 violated on a green board).
- HOLE 2 (the real one, confirmed by ruling): `di_nlink=0` travels in the INODE LOG ITEM; `xfs_log_force(SYNC)` makes it durable only in OUR journal, which no peer replays; nothing converts inode items → cluster buffer at AG release, so the buffer is CLEAN and both in-core and medium say LINKED — P85 is structurally blind. Hazard covers every inode-resident field (mode, size, gen, forks…). Option (b) buffer-logging di_nlink REJECTED (dual logging authority, range-granularity replay of stale neighbours, v3 CRC/LSN rules); option (a) bucket walk = containment only. Fix = option (c) real publication/quiescence stage: stop admission → wait users → log force → flush dirtied inode items into cluster bufs → sync write → AG metadata → flush → verify no new dirty gen → unlock. Previous AIL-push attempts deadlocked because the worker took ILOCKs while ILOCK holders waited on the worker — if any thread can hold ILOCK_EXCL while waiting on the BAST worker the protocol is deadlockable. Pointee-before-pointer order (inode bufs before AGI); ordering alone never makes the txn atomic under crash takeover.
- PROVEN at the publication point (P86-AGI-UNLINKED-PUBLISH, `mxfs.agi_publish_audit`, FUA-reads each bucket head's home dinode just before `mxfs_v5_dlm_ag_unlock`): 1 of 5 heads SPLIT (test26 AG6 ino 25165958 disk_nlink=1 core_nlink=0). Control arm: 167 heads, 3 SPLIT + 4 BADHEAD (4.2%; 17% on another lap). `core_nlink=-1` (BADHEAD) = not in THIS node's cache — usually a re-published head another node left bad; attribute before blaming the fix.

## Rulings

Unreadable/inconsistent descriptor => treat as FROZEN. Adding the freeze is safe (victim still holds the AGs); removing only after completion metadata is HOME-WRITTEN and OBLIGATIONS_DONE durable. Validate before publishing IMAGES_REPLAYED+mask: every RECOVER extent's AG in mask; every such AG in the sealed fence-time manifest; mask cannot truncate (else fswide); slice immutable until OBLIGATIONS_DONE.
- Q2 no persistent per-extent dedup ledger needed IFF: peers cannot allocate the AG; ordinary LOCAL activity on the owner cannot allocate it (SS1); predecessor owner's committed metadata replayed before F6 (SS2); no replacement EFI (SS3); F6 check + free serialized under AGF in one txn; AG frozen until completion metadata visible. Source EFI identity stays as evidence/P-lines. Overlapping or duplicate RECOVER extents (also across EFIs) => quarantine, never 'already done'.
- Q3 NO recursion via owner-slice EFIs. Completion = direct single-txn free, buffer images logged in the owner txn, no new EFI/EFD. Crash window: owner commits free, dies before OBLIGATIONS_DONE, successor reads home bnobt before the owner's slice images are replayed => EMPTY => double free. Therefore: before transferring an AG from a DEAD PRIOR RECOVERY OWNER, that owner's slice must be foreign-replayed (admitted images) and flushed home. Transfer only from (a) the original victim or (b) a dead prior owner whose slice is >= IMAGES_REPLAYED and flushed. Termination: each extent changes once; freeze prevents reallocation; finite failures.

- Q5 do NOT assume 'separate defer type => not an EFI on disk': audit xfs_agfl_free_defer_type.create_intent/create_done/relog_intent and the recovery chooser; unsupported subtype/flags => quarantine until audited.

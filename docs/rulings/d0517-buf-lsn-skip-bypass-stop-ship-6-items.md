# sess459 RULE-5 ruling — D-0517 buffer-path cross-slice LSN skip (2026-09-02 ~02:50Z)

Proposal reviewed: on untrusted replay, skip the upstream `disk lsn >= txn lsn` veto in xlog_recover_buf_commit_pass2 for images that reached pass 2 (token verdict APPLY). GPT: the core conclusion is correct (a foreign slice LSN must not veto an authoritative image) but STOP-SHIP as written.

## Required changes
1. Bypass predicate = `item verdict == APPLY` (exact authority/lineage check), NOT "untrusted replay" or "clustered". REDUNDANT_CLEAN never reaches pass 2; untagged/unsupported/stale-lineage fail closed.
2. APPLY must mean TERMINAL protected tenure: resource stays fenced after death, no successor grant before replay completes, replay cannot repeat after a successor tenure. Owner epoch + lineage must reject: earlier tenure by same node; victim recovered before successor grant; historical victim re-encountered at bootstrap; earlier failed owner when a later failed owner held the resource. If the protocol persists "replay completed before successor grant", document + assert it.
3. Audit authority scope per block class; fail closed for unproved classes. Likely safe after audit: AG headers/btrees under AG tenure; dir/bmap/da/remote-attr/symlink + inode clusters IF every modification is serialized by the same inode DLM resource and drained before release. NOT established: primary SB / per-node SB images (keep the LSN check), dquots/shared quota blocks (keep), RT metadata (keep), mixed-ownership buffers.
4. Do NOT change xlog_recover_dquot_commit_pass2 "for consistency".
5. Preserve all non-LSN validation (buffer-type validation, verifier attach, UUID/owner checks, cancel table, malformed rejection). Token = permission to write, not validity of the image.
6. Clustered OWN-slice recovery is equally exposed to cross-slice stamps: standalone trusted recovery keeps upstream; clustered replay with proven APPLY ignores the stamp; clustered replay WITHOUT an authority verdict must not replay by merely disabling the compare. Every dirty clustered slice (incl. own slice after whole-cluster crash) must go through authority admission — make it an asserted invariant, not an incidental call-path property.

## Q&A
- Q1 same-slice ordering: no load-bearing case beyond idempotent re-application (T2's metadata cannot hit disk before its commit is durable; lagging tail only ADDS old txns; replay is in order; partial-region logging correct; free/reuse via the slice's cancel table). Caveat is only the successor-lineage issue.
- Q2 no cheap sound discriminator exists in the stamp (window membership, txn-table equality, cycle plausibility all unsound). Trust the proven verdict, ignore the stamp; no heuristics. A sound discriminator would need new persistent identity (writer slice/incarnation + LSN, or a global txn generation).
- Q4 verification: (A) deterministic same-slice "newer image already on disk" arm — pin tail, T1 then T2 modify B, force T2's buffer to disk, crash; prove T1 applied despite T2's stamp, T2 re-applied, final = T2 (also partial-region variant; also crash mid-recovery + re-run). (B) cancellation/reuse arms (same-slice free, type change; victim frees + clean release + successor reuse; same-node reacquisition after intervening owner). (C) sequential-victim lineage arm: A holds AG X, writes, dies; B later acquires X, writes, dies; bootstrap replays in both orders; A's images must never overwrite B's tenure. (D) stress: postmark churn, dir split/join, attr remote blocks, bmap/rmap/refcount, log wrap + lagged tails, repeated pass-2 failures, ≥2 victims on one AG in successive tenures, verifier corruption injection, unsupported quota/RT/SB configs fail closed. Instrumentation must distinguish LSN_WOULD_SKIP_BUT_APPLY vs actual LSN_SKIP vs REDUNDANT_CLEAN vs stale-lineage vs classless. For APPLY images actual SKIP must be 0; nonzero would-skip proves the path is exercised.
- Q5 own-slice: same reasoning; do not disable globally; require an authority verdict; bootstrap-adopt routing acceptable if asserted.

## Hazards GPT could not rule out
Successor tenure between death and (a repeated) replay; incomplete persistence of replay-completion/grant-lineage; same-node reacquisition mistaken for continuation; mixed-authority buffers (quota); primary/per-node SB semantics; RT metadata; cross-slice free/reuse if lineage admission does not suppress the obsolete slice (per-slice cancel table alone cannot); loss of verifier attach/type validation; any write path violating log-before-data or drain-before-release; atomicity between changecount-gated inode items and token-gated buffer items when classifications differ.

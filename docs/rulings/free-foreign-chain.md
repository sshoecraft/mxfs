# sess430 — D-0351 chain: GPT ruling on the FREE-FOREIGN reclassification

## Evidence brought
s433 board (0.39.0, clean): 164 P55C-FREE-FOREIGN / 63 inos, all reg files, 0 with disk_gen==gen-1, single-node per ino, signature FOREIGN -> P-RECYCLE-DEADSTAMP-CLEAR repeating up to 5 laps; 634 P-FREEOB-FOREIGN (audit); 1 P32D-DEADINCARN-SKIP on a live file. Mechanism: XFS_IRECLAIM_RESET_FLAGS clears MXFS_IF_PUBOB at recycle, store entry stays kind=FREE; life 2 never flushed; its free finds life 1's live image at gen G != R -> FOREIGN -> never written -> inobt free + platter LIVE (latent DISK-LIVE for the first peer allocator).

## Ruling
1. Tenure continuity (pubwrite_begin(ob.epoch) / retiring token) is NECESSARY but not sufficient: require explicit chain provenance recorded at the recycle transition under the same epoch. Preconditions it named: AG EX must exclude stale peer inode writers (not just allocation); foreign replay must not write concurrently with a granted EX; chain anchor must be trusted (adopt/deadshell paths must not bootstrap a "local chain" from a foreign image); retiring-token path quiescent; cluster writes coherent for adjacent dinodes. Fresh-EX recovery worker keeps FOREIGN/neutralize.
2. The recycle-time gap is an INDEPENDENT hazard: a live inode must never be represented by an actionable FREE entry (audit could write mode 0 over / poison / target-flush-and-refuse a live inode). Needs a transactional state: FREE -> CHAIN_LIVE(epoch, chain) -> FREE(new gen, same epoch, chain+1). "keep FREE + chained flag" REFUSED. Reclaim refusal must not rely solely on MXFS_IF_PUBOB; P237 poison exemption only for terminal FOREIGN-neutralized shells.
3. Alternative publish-before-recycle (sync write at recycle) is the smallest state space; costs an I/O per hot reuse; skipping numbers creates allocator hot spots. Chaining is the better performance design if it is a real state machine (chosen).
4. Measure: chain counts/max length, pubwrite success/failure by classifier, audits seeing CHAIN_LIVE, worker FOREIGN after fix (should be exceptional), reclaim refusals, poison exemptions. Reproducer must show: P55C-FREE-CHAIN for chain inos, platter mode 0 at final gen before unlock, no FOREIGN for same-tenure chains, peer allocates without P-CR62, fresh-EX recovery still loud.

# sess427 GPT rulings — D-0351 (ifree dinode never published; inobt free visible; peer double-alloc → shutdown)

## Ruling 1 (evidence + first proposal "keep RELFLUSH in INACT-DEFER")
- NAK as complete fix; acceptable only as emergency mitigation. A sticky bit is unsafe unless it denotes the SAME uninterrupted EX tenure the ifree committed under; a current-mode query alone cannot distinguish release+reacquire.
- Invariants: A continuous-tenure; B release serialization (block new sanctioned entrants, wait entrants out, force log/unpin, flush mode=0, wait I/O completion, then clear sanction, then release); C no untracked release path; D flag must not survive object reuse; E sanction applies only to the exact committed ifree state.
- **FREE-PUBLISH invariant**: a peer may select an inode as free under a newly acquired AG grant only if the matching free dinode (mode=0, correct incarnation) is already durable. "Same AIL push" is not an ordering guarantee. Enforce at AG-grant handoff: force ifree LSN, unpin, sanctioned cluster write, completion, flush, then unlock.
- Containment: platter-live validation BEFORE dialloc dirties the transaction (skip candidate / clean retry; exclusion set to avoid livelock; authoritative read, not a cache hit; lock-order audit).

## Ruling 2 (concrete design review)
Approved direction with changes; REFUSED: (1) bare `READ_ONCE(pag_mxfs_grant_epoch)==ob->epoch` predicate — TOCTOU between read and copy-in/delwri registration vs the release's drain snapshot → need a counted publication gate (begin: reject if releasing/epoch 0/mismatch, inc writer count; end after dirty/delwri registration is visible; release: set releasing, clear epoch, wait writers==0, then drain to a fixed point). (2) arming the FREE obligation first after xfs_trans_commit (gap between unlink discharge and FREE insertion) → UNLINK→FREE_PENDING→FREE_COMMITTED must be continuous; audit treats FREE_PENDING as defer-only; epoch 0 at ifree = protocol failure. (3) the audit's own flush can never pass an active-epoch predicate (epoch cleared before audit) → define a retiring-epoch token (pag_mxfs_rel_epoch == ob->epoch, release owns the still-held grant, unlock not yet done); RELFLUSH must not be a free bypass. (4) unconditional mode==0 discharge → classify: {mode=0, gen==ob.gen} published/discharge; {mode!=0, gen==ob.gen-1} exact stale predecessor: repair under token; any other gen: NEVER write, loud, neutralize the stale item (dead_incarn) then discharge; read/CRC failure: defer/escalate; shell absent for the exact predecessor: unrepairable → quarantine/defer/escalate. Use modular equality on di_gen, never ordering. (5) AG-only sanction for ICLUSTER-routed inodes unless an authority-subsumption invariant is documented/asserted (no legitimate cluster writer of a dead incarnation). (6) inline FUA read/repair inside the ialloc AGI/inobt lock nesting — two-phase candidate validation, quarantine set, restart; consult the local pubob store first but never flush inline. (7) indefinite AIL-tail pinning: bounded; recovery worker acquires the AG outside AIL context, or obligation holds a reconstructable payload (shell-less direct repair) so the item can be laundered after recording recovery state. "Publish under protest" must not allow allocation from the AG as if publication succeeded.

# sess428 GPT ruling #2 — D-0349 redesign at format-v2 geometry (2026-08-28)

Facts given: v2 ledger = 67,651 pages (31 rec/page), per-page durable authority header; eager per-page activation REFUTED in usermode ramp (16/tick: ~1 page/pass, stale EX record + 33 rel re-sends; 2/tick+(c): 12 lock failures, 9× -110); any per-page handoff on a view change is O(pages) writes; lazy first-touch ≥100 ms × ~5000 pages for the workload. Requirement ≤ 6 s (2× native) for the 4-node small-file workload.

## Decision
- **B = target**: a durable VIEW TABLE (range → owner incarnation per table generation), double-buffered slots + CAW-switched ROOT pointer; 2-phase barrier on membership change (PREPARE(Gnew,Gold,digest,moved_ranges,memb_digest,coord_term) → each node: verify Gold current, freeze new requests on moved ranges, cancel/finish old-routed queued requests, block new old-gen commits, wait admitted old-gen commits durable/failed, persist the promise (or crash = re-admission), ACK exact digest → coordinator CAW-commits root → nodes validate committed root, new owners open admission, requesters reroute). ACK = "no op initiated/admitted by me can commit under the old assignment for any moved range"; missing ACK is NEVER converted by timeout — node returns or is removed+storage-fenced+ranges recovered/drained. Every grant commit carries table generation + deciding owner incarnation + page lineage/seq (provenance, not expiry). Old grant records stay valid blockers; new owner's first decision on a page = ordinary lazy page import (no ownership transition, no park). Coordinator death: replacement reads root — Gold → abort/unfreeze or retry exact proposal (after ensuring old coord cannot CAW); Gnew → finish dissemination, never roll back; ambiguous → stop, recover from redundant root. Late joiner: fresh incarnation, read/validate root, no authority until a later committed generation maps ranges to it; crash after ACK → fenced/re-admitted. Per-page owner field loses authority semantics at one explicit barrier (may stay for diagnostics).
- **A (page-GROUP authority, e.g. 64 pages → 1057 groups)**: legitimate bounded interim ONLY as real group authority (one durable gen/incarnation per group, admission closes for whole group, all pages drain, lazy per-page import); grants stay PAGE-scoped so B remains straightforward. Not the endpoint (geometry-proportional handoff, coupling, hot groups, format churn).
- **C (claim-on-first-grant for UNOWNED)**: false-death objection does NOT hold if: claim+first grant = one CAW vs exact fresh UNOWNED image; grant not effective until durable; CAW loser rereads/obeys; survivor never overwrites foreign ACTIVE on view change alone; takeover of foreign ACTIVE needs ordered handoff or confirmed storage fence + recovery/drain; PR preempt resolves outstanding writes; incarnations never reused. Fixes first formation only; not selected.
- **D (wake-on-FROZEN instead of 100 ms park)**: fixes a polling artifact, not the shape.
